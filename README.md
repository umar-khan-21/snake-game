# Neon Snake

A small, responsive Snake game that runs directly in your web browser. It is built with plain HTML, CSS, and JavaScript; no install or build step is required.

## Play

Open `index.html` in a modern browser, then select **Start game**.

## Controls

- **Arrow keys** or **WASD** to steer
- On phones, swipe across the board or use the directional buttons
- **Space** or **Pause** to pause and resume
- On touch screens, use the directional buttons below the board
- Use the difficulty menu to choose Easy, Normal, or Hard
- Use **Sound on/off** to toggle game sounds

Eat the glowing food to gain 10 points. Catch the occasional golden star before it disappears for a 30-point bonus. Avoid the walls and your own tail. Your best score is saved in this browser using local storage.

## Files

- `index.html` — the complete game, including its styles and game logic
- `README.md` — this guide

## Run locally

No server is needed. Double-click `index.html` or open it from your browser. If you prefer a local server, run `python -m http.server` in this folder and visit `http://localhost:8000`.
